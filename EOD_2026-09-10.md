## Tasks Completed

### 1. Comments: Show all comments across every video (Newest / Oldest / Top)

**Problem:** The main tutorials page loaded comments with `video_id=general`, so only "general" comments appeared. The Newest/Oldest/Top sort buttons only sorted within general comments — comments posted on specific videos (e.g. `dashboard`, `my-drivers`) were never visible on the main page.

**Root cause:** `fetchComments()` always passed `video_id=general` to the API; the API already supports returning all comments when `video_id` is omitted.

**Changes:**
- `js/comments.js` (→ `?v=11`, then `?v=12`):
  - Added `showAllComments = true` flag.
  - `fetchComments()` now omits `video_id` when the flag is set, fetching comments across all videos.
  - Added `videoIdToTitle()` helper mapping a `video_id` to its video title via `window.VIDEOS`.
  - Each top-level comment renders a `.comment-video-badge` labeling which video it belongs to.
- `css/comments.css` (→ `?v=11`, then `?v=12`, `?v=13`):
  - Added `.comment-video-badge` styling (pill badge, accent play icon, ellipsis truncation).
- `tutorials.php`: bumped `comments.css` and `comments.js` cache-busting versions.

**Result:** The Newest / Oldest / Top buttons now sort across all comments from every video, each labeled with its source video. New comments posted from the main form are still tagged `general` (posting context unchanged). The modal's per-video comment list is untouched and stays scoped to the open video.

### 2. Up-next auto-queue indicator (YouTube-style)

**Problem:** When a tutorial video ended in the modal, nothing happened — the user had to manually pick the next video from the related sidebar.

**Changes:**
- `js/tutorials-player.js` (→ `?v=12`, then `?v=13`):
  - Added module state: `upNextVideo`, `upNextTimer`, `UPNEXT_DURATION = 3000`ms (autoplay on), `UPNEXT_DURATION_MANUAL = 8000`ms (autoplay off).
  - `renderRelatedVideos()` sets `upNextVideo` to the first related video (the queue).
  - `showUpNext()` builds a glassmorphic card in the bottom-right of the video frame with the next video's title, a countdown ring (autoplay) or "Play next (N)" button (manual), and a × cancel button.
  - `hideUpNext()` clears the timer and removes the card.
  - `video.onended` triggers `showUpNext()`.
  - `openModal()` and `closeModal()` call `hideUpNext()` for cleanup.
- `tutorials.php`:
  - Added full `.upnext-bar` CSS — glassmorphic card, accent play-thumb, SVG countdown ring (stroke-dashoffset animation), "Play next" button variant, cancel button.
  - Responsive rules at 640px / 560px / 400px breakpoints.
  - Reduce-motion fallback.

**Behavior:**
- **Autoplay ON** → 3-second countdown ring, auto-advances at 0.
- **Autoplay OFF** → "Play next (8)" button with live countdown badge; auto-advances after 8s if the user doesn't click Play next or ×.
- Either button cancels the timer.

### 3. Comment video badge is clickable

**Problem:** The video badge added in task 1 was display-only; users couldn't jump to the video a comment belonged to.

**Changes:**
- `js/comments.js` (→ `?v=12`):
  - Badge is now a `<button>` with `data-video-id` instead of a passive `<span>`.
  - `wireCommentActions()` binds a click handler that looks up the video in `window.VIDEOS` by id and calls `window.openModal(target)`. Click uses `stopPropagation()` so it doesn't bubble to the comment item.
  - Shows a toast if the video id can't be resolved.
- `css/comments.css` (→ `?v=12`):
  - Restyled `.comment-video-badge` as a proper button — accent-tinted hover state, border, cursor, play-icon scale on hover.

**Result:** Clicking a video badge on any comment opens that video's tutorial modal with the player, related videos, and its own comments — making cross-video comment browsing navigable.

### 4. Responsive audit and fixes

**Problem:** The newly added upnext bar and comment video badge weren't fully covered at the smallest breakpoints; some comment UI elements lacked explicit ≤400px rules.

**Audit performed:** Reviewed all 7 `@media` breakpoints in `tutorials.php` (1024 / 768 / 640 / 560 / 400 / 640-upnext / 1024-modal) and the comments.css 640px rule. Verified modal layout, grid, sidebar, header, chips, cards, and comments at each width.

**Gaps found and fixed:**
- `tutorials.php` — Added upnext-bar rules at ≤560px (shrinks thumb/ring/play/cancel) and ≤400px (hides thumb icon, caps title width at 90px).
- `css/comments.css` (→ `?v=13`):
  - ≤640px: `.comment-video-badge` max-width 120px.
  - ≤400px: badge max-width 90px, smaller font/icon; smaller comments header h2 (1.1rem) and icon; tighter sort buttons and comment action buttons; reduced modal comments list max-height (300px).

**Result:** The upnext card, comment badges, sort toggle, and action buttons scale cleanly down to 320px.
